# Footwear Laundry — Web Platform

> **Every pair, perfection.**

A full-stack web platform built for **Footwear Laundry**, a Johannesburg-based premium sneaker and footwear cleaning service.

The platform provides customers with information about the business and services, allows them to submit cleaning bookings online, and provides administrators with a dashboard to manage bookings.

## Live Site

🌐 [footwearlaundry.co.za](https://footwearlaundry.co.za/)

## Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS
* **UI:** shadcn/ui
* **Animations:** Framer Motion
* **Routing:** React Router
* **Backend & Database:** Supabase / PostgreSQL
* **Authentication:** Supabase Auth
* **Contact Form:** Formspree
* **Deployment:** Vercel
* **Version Control:** Git

## Key Features

* Online footwear cleaning booking system
* Automatic booking reference numbers
* Admin dashboard for managing bookings
* Admin authentication and role-based access
* Booking status management
* Contact form with email delivery
* Service pre-selection from the Services page
* Responsive design for mobile, tablet and desktop

## Local Development

### Prerequisites

* Node.js 18+
* Git
* Supabase project

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Bongiwe01/Footwear_Laundry.git
cd Footwear_Laundry
npm install
```

Create a `.env` file in the project root:

```env
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_PUBLISHABLE_KEY=your-supabase-key
```

Start the development server:

```bash
npm run dev
```
